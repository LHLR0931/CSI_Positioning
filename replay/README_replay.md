# Developer Replay data — D1 held-out rounds r9 / r10

Files: [replay_d1_r9r10_seed42.json](../unity-app/Assets/Resources/Replay/replay_d1_r9r10_seed42.json) (meta + records, bundled in the app) and [replay_d1_r9r10_seed42.csv](replay_d1_r9r10_seed42.csv) (same records, flat). The JSON is kept once in Unity Resources, byte-identical to the supplied export (SHA-256 `e8204a79b98e4d3cae7b2a2350a23fe1848fda0449c8dad360234065d7d9d9ae`).
Generated by `backend/training/export_replay.py`. No new capture, no retraining: the saved D1 final-phase
models were loaded and run once on the two held-out rounds.

## Capture
- Date: 2026-10-08 (Sydney, AEDT +11:00). Site: home, 5 x 3 grid, 0.8 m spacing, `label = y*5 + x`.
- 4 links (piA_apX, piA_apY, piB_apX, piB_apY), 5 GHz ch36 / 20 MHz, device-free (person carries nothing).
- One round = the person stands on all 15 points in turn, about 41 s per point (snake order).
- r9: 13:27–13:42, starts 2.4 min after the calibration round ended. r10: 14:04–14:19, starts 39.7 min after.

## Windows
- 16 consecutive aligned frames per window (~1.6 s at ~10 fps), non-overlapping, never crossing a point.
- About 25 windows per point; r9 = 375 windows, r10 = 376 windows.
- `window_index` / `window_id` are numbered in time order within each round; the same window has one record per model.
- `point_window_index` = position of the window within that point's 41 s.

## Models (all four present)
| model | what it is |
|---|---|
| KNN | 4-link KNN, k = 5, distance-weighted, on time-averaged amplitude+phase |
| GCN | sample-graph GCN (prior RSSI+GNN structure), same features and k as KNN |
| ConcatMLP | shared 2D-CNN encoder per link, concatenated, MLP head, end-to-end |
| ConcatMLP-mask | ConcatMLP + random link masking during training (p = 0.25) |

Version: `d1-final-cls_ampphase_pp2-seed42` (15-class classification, amplitude+phase, preprocessing pp2, seed 42).
Weight file names and md5 are in `meta.models` of the JSON.

## Was this data used for training, calibration or tuning?
- Training: no. Models were trained on r1–r8 only (r8 = calibration round after the piB restart).
- Calibration: no. r8 is the calibration round; r9 / r10 come after it.
- Early stopping / hyper-parameters: no. Training length was fixed from an earlier model-selection phase in
  which r8–r10 were not visible at all.
- Caveat: the aggregate scores on r9 / r10 had already been looked at during the project, so they are
  reported as diagnostic, not as a fresh blind test.
- Label it as **held-out test replay**, not calibration/training replay.

## Fields
`true_label` comes from the station label recorded at capture time. `pred_label` = argmax of `probs`.
`error_m` = Euclidean distance between true and predicted grid points in metres.
`confidence` = max of `probs`. For GCN / ConcatMLP / ConcatMLP-mask, `probs` is a softmax (not calibrated).
For KNN, `probs` is the distance-weighted vote of 5 neighbours, so values are coarse (exactly 1.0 when all 5 neighbours agree).
Timestamps (`t_start`, `t_end`) are the first / last frame of the window, averaged over the 4 links.

## Notes for the UI
- These are one seed (42). The thesis tables average 3 seeds, so on-phone numbers will not match them exactly.
- A classification model's error is usually 0 or 0.8 m; show accuracy next to mean error.
- The thesis's final model (F-MLP) is not in this file; it was only trained for the later D+3 data.
